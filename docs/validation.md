# การตรวจสอบความถูกต้อง (Validation)

เอกสารนี้เปรียบเทียบค่าที่โปรแกรมคำนวณกับค่าที่คำนวณด้วยมือจากสมการในใบงาน
เพื่อยืนยันว่า Backend คำนวณจริง ไม่ใช่ค่าคงที่ที่เขียนไว้ใน HTML

## สมการที่ใช้ (Forward-Active, β และ VBE คงที่)

```
VTH = VCC·R2/(R1+R2)          RTH = R1·R2/(R1+R2)
IB  = (VTH − VBE)/(RTH + (β+1)·RE)
IC  = β·IB                    IE = (β+1)·IB
VE  = IE·RE                   VB = VE + VBE
VC  = VCC − IC·RC             VCE = VC − VE
```

## กรณีที่ 1 — Active Region (ค่าตัวอย่างในใบงาน)

VCC = 12 V, R1 = 100 kΩ, R2 = 22 kΩ, RC = 2.2 kΩ, RE = 1 kΩ, β = 100, VBE = 0.70 V

| ปริมาณ | คำนวณมือ | โปรแกรม | ตรงกัน |
|--------|----------|---------|--------|
| VTH | 2.1639 V | 2.1639 V | ✅ |
| RTH | 18.0328 kΩ | 18.0328 kΩ | ✅ |
| IB | 12.2986 µA | 12.2986 µA | ✅ |
| IC | 1.2299 mA | 1.2299 mA | ✅ |
| IE | 1.2422 mA | 1.2422 mA | ✅ |
| VE | 1.2422 V | 1.2422 V | ✅ |
| VB | 1.9422 V | 1.9422 V | ✅ |
| VC | 9.2943 V | 9.2943 V | ✅ |
| VCE | 8.0522 V | 8.0522 V | ✅ |
| Region | Active | Active | ✅ |

## กรณีที่ 2 — Cutoff (R2 = 5 kΩ)

VTH = 12 × 5/(100+5) = **0.5714 V** ซึ่งน้อยกว่า VBE = 0.70 V
ดังนั้น IB = IC = IE = 0 ตามเงื่อนไขที่โปรแกรมบังคับ

| ปริมาณ | โปรแกรม |
|--------|---------|
| VTH | 0.5714 V |
| VB | 0.5714 V (= VTH เพราะไม่มีกระแส Base) |
| VE | 0 V |
| VC | 12 V (= VCC เพราะไม่มีกระแส Collector) |
| VCE | 12 V |
| Region | **Cutoff** + Warning |

Warning ที่ได้:
> VTH (0.571 V) ≤ VBE (0.70 V): ทรานซิสเตอร์อยู่ในช่วง Cutoff ค่าที่แสดงเป็นการประมาณ ไม่ใช่ผลจำลองที่แม่นยำ

## กรณีที่ 3 — Saturation (RC = 15 kΩ)

สมการ Forward-Active ให้ IC = 1.2299 mA ซึ่งมากระแสสูงสุดที่วงจรรับได้
IC(sat) = VCC/(RC+RE) = 12/(15+1) = **0.750 mA**

| ปริมาณ | โปรแกรม |
|--------|---------|
| IC (ตามสมการ) | 1.2299 mA |
| IC(sat) | 0.7500 mA |
| VC | 12 − 1.2299×15 = **−6.4479 V** |
| VE | 1.2422 V |
| VCE | **−7.6900 V** |
| Region | **Saturation** + Warning |

Warning ที่ได้:
> VCE ที่คำนวณได้ (-7.690 V) ≤ 0 V: สมการ Forward-Active ใช้ไม่ได้ ทรานซิสเตอร์อิ่มตัว (IC(sat) ≈ 0.750 mA)

## เหตุใดค่าที่ติดลบจึงไม่ควรเชื่อถือ

ค่า VC และ VCE ที่ติดลบเป็นผลจากการใช้สมการ Forward-Active เกินขอบเขตที่สมการนั้นใช้ได้
ในวงจรจริง ทรานซิสเตอร์จะอิ่มตัว (VCE ≈ 0.2 V) ไม่ใช่ค่าติดลบ
โปรแกรมจึง **ไม่ปรับค่าให้ดูสมเหตุสมผล** แต่รายงานค่าตามสมการพร้อม Warning
เพื่อให้ผู้ใช้เห็นว่าแบบจำลองหลุดออกนอกช่วงที่ใช้ได้
